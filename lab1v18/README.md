## Контрольні питання

**1. Що таке клас та об'єкт? Яка між ними різниця?**

Клас - це шаблон, який визначає, які дані та методи матимуть його екземпляри. Об'єкт - це конкретний екземпляр класу, створений у пам'яті через new. Наприклад, Bookstore - клас, а store1, store2, store3 - об'єкти цього класу.

**2. Для чого використовуються конструктори? Чи може клас існувати без них?**

Конструктор ініціалізує початковий стан об'єкта одразу під час його створення. Клас може існувати і без явно написаного конструктора - тоді компілятор автоматично додає конструктор за замовчуванням.

**3. Чим відрізняється приватне поле від публічної властивості? Навіщо потрібна інкапсуляція?**

Приватне поле доступне лише всередині самого класу. Публічна властивість (get/set) - контрольована точка доступу до поля ззовні, яка дозволяє перевіряти коректність даних (наприклад, щоб BooksAvailable не було від'ємним). Інкапсуляція захищає внутрішній стан об'єкта від некоректних змін.
